# Logistic Regression Classifier

## Files
- `logistic_regression_training.ipynb` - notebook used to train and evaluate this model.
- `model.joblib` - saved trained model, generated by running the notebook.
- `metrics.json` - evaluation scores, generated by running the notebook.

## How to run
Open Jupyter Notebook from the main `CareLoop` folder. Open `logistic_regression_training.ipynb` and run all cells from top to bottom.

The notebook uses the existing files in `data/processed`. It does not repeat preprocessing.

## Model idea
Logistic Regression estimates the probability of the positive class and is used here as a classification baseline.
