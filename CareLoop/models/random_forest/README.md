# Random Forest Classifier

## Files
- `random_forest_training.ipynb` - notebook used to train and evaluate this model.
- `model.joblib` - saved trained model, generated by running the notebook.
- `metrics.json` - evaluation scores, generated by running the notebook.

## How to run
Open Jupyter Notebook from the main `CareLoop` folder. Open `random_forest_training.ipynb` and run all cells from top to bottom.

The notebook uses the existing files in `data/processed`. It does not repeat preprocessing.

## Model idea
Random Forest combines predictions from many decision trees to produce a classification result.
